# Projeto Som — regras para qualquer sessão

- Antes de continuar um projeto, leia `perfil.md` e o `andamento.md` do projeto (ex.: `projetos/home-theater-2.1/andamento.md`).
- **No fim de cada sessão de trabalho num projeto, atualize o `andamento.md`**: passos feitos, medições, próximo passo, pendências e uma linha no "Registro das sessões". Decisões com motivo vão também para o histórico do `projeto.md`.
- O que for aprendido sobre o funcionamento de um equipamento ou app vai para `componentes/<categoria>.md`; **toda configuração salva no processador (ou em qualquer equipamento) é registrada no mesmo momento** em `projetos/<projeto>/memorias-processador.md`, com todos os valores por canal, data e versão; prints e fotos para `projetos/<projeto>/fotos/<data>-<assunto>/`.
- Depois de salvar, faça commit e push no branch da sessão.
